# DIO JS Pokédex

Projeto de estudo desenvolvido durante a formação JavaScript Developer da DIO.

A aplicação consome dados públicos da PokéAPI e apresenta uma Pokédex responsiva construída com HTML, CSS e JavaScript puro.

## Funcionalidades implementadas

- consumo da PokéAPI com `fetch`;
- listagem dinâmica de Pokémon;
- exibição de número, nome, tipos e imagem;
- cores dos cards conforme o tipo principal;
- carregamento incremental com botão "Carregar mais";
- layout responsivo;
- uso de official artwork com fallback de sprite.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- PokéAPI
